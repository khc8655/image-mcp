EdgeOne 凭据中枢 (Vault Central)

所有厂商的 API Key 统一由 EdgeOne 中枢托管。点击「一键同步全部凭据」将自动对齐所有已授权厂商与密钥，本地无需手动维护。

模型适配规则库 (Presets Engine)

包含 Google Gemini、MiniMax、SenseNova、Agnes AI 等厂商的官方协议驱动与长宽比规范。新增或优化模型只需更新规则文件，主程序免重启免改代码。

访问安全与服务状态 (Security & Runtime)

管理端 Admin Token 同时也是 MCP 客户端调用 /mcp 端点时的 Bearer 鉴权凭证。
